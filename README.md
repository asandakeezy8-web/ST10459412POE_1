## Project Description
This is a Java console application that handles user registration and login. It validates username, password, and South African cell phone number format.

## Features
- Username validation (must contain underscore and be <=5 chars)
- Password complexity check (8+ chars, capital letter, number, special char)
- Cell number validation (+27 international format with regex)
- Registration and login functionality
- JUnit 5 unit tests

## How to Run
1. Clone the repo
2. Open in Apache NetBeans (Java Maven project)
3. Clean and Build
4. Run `com.mycompany.main.Main`
